# wavelet-lab
Interactive web app for wavelet-based signal analysis, denoising, and compression — powered by PyWavelets and Flask.

## Overview

Wavelet Lab is an experimental web application for exploring wavelet techniques on real-world signals.

The project currently focuses on seismic data and integrates:

- **USGS earthquake catalog** for discovering seismic events.
- **EarthScope** for retrieving seismic waveform data from monitoring stations.
- Interactive visualization of seismic time series using **Plotly**.
- **Continuous Wavelet Transform (CWT)** analysis.
- Comparison of different wavelet families and their parameters through interactive controls.

## Technologies

- Python
- Flask
- PyWavelets
- NumPy
- Plotly
- JavaScript

## Work in progress

The project is under active development. Planned experiments include wavelet-based event analysis, SVM classification, and event-based sampling techniques.
